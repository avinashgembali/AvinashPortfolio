About Me

Product Developer & Tech Enthusiast

My journey began with a full-stack foundation — Angular, OvernightJS, and MongoDB — and evolved as I worked on larger, more complex systems that introduced me to modern frontend architecture, microservices, cloud-based workflows, and distributed systems.

I enjoy understanding how things work beyond just writing code — from how a frontend communicates with an API gateway, to how microservices talk to each other, how files are securely stored and processed, and how scalable systems are designed.

I'm particularly interested in scalable web applications, microservices, distributed systems, and cloud technologies. Currently, I'm continuing to learn and grow by working with real production systems and exploring the architecture behind the products I help build. 🚀 Always learning. Always building.
